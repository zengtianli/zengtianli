### 曾田力 · Tianli



A full-stack engineer building things I use every day: native iPhone / macOS apps, Python backends and LLM agents, Next.js sites, and a self-managed VPS. I trained as a water-resources engineer, which is why the agents and calculators are rooted in that domain.

**Actively maintained and used**

- [WeChatTweak](https://github.com/zengtianli/WeChatTweak) — Message-recall prevention for WeChat 4.x. Maintained after upstream stopped: byte patches + blocking automatic updates + one-command restoration, in a Swift CLI
- [WeChatUnrevoke](https://github.com/zengtianli/WeChatUnrevoke) — A one-click graphical interface for that engine; `brew install --cask zengtianli/tap/wechat-unrevoke`
- [homebrew-tap](https://github.com/zengtianli/homebrew-tap) — Homebrew distribution for both

**iPhone fleet** (2026-08-18 to 08-31: from the first line of Swift to 10 native apps in 14 days, 9 on TestFlight, roughly 21,000 lines)

- [hydro-deck](https://github.com/zengtianli/hydro-deck) — The water-sector agent's mobile client: SSE streaming, visible steps, cited answers, and recovery after disconnects
- [wrong-book](https://github.com/zengtianli/wrong-book) — A primary-school mistake book: retest a missed question type with a new question, and import whole papers with the system document scanner
- [fitcoach-ios](https://github.com/zengtianli/fitcoach-ios) — The mobile lesson-management client built for a real coach, sharing one backend with the web and mini-program clients
- [options-calc](https://github.com/zengtianli/options-calc) · [options-desk](https://github.com/zengtianli/options-desk) — An options-seller decision workbench / investment dashboard
- [points-deck](https://github.com/zengtianli/points-deck) · [day-deck](https://github.com/zengtianli/day-deck) · [blog-reader](https://github.com/zengtianli/blog-reader)
- How it was done: [From Zero to TestFlight: The Complete Path to Building an iPhone App Alone](https://blog-ai.tianli.cyou/nine-ios-apps-in-two-weeks)

**macOS**

- [hydro-mac](https://github.com/zengtianli/hydro-mac) — Eight water-sector calculators in one app (Rust calculation core + SwiftUI)
- [ask-claude](https://github.com/zengtianli/ask-claude) — Ask Claude directly on Mac using subscription allowance, without another key
- [doc-tools](https://github.com/zengtianli/doc-tools) — Batch normalization / conversion / template-based Word generation
